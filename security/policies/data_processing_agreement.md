# Data Processing Agreement

## Data Controller
The Client organization acts as the data controller for all personal data processed during the engagement.

## Data Processor
Cerberus AI acts as the data processor, processing data solely for the purpose of security assessment.

## Data Categories
- User account information (name, email, company)
- Organization infrastructure data
- Security assessment results and findings
- Audit logs and access records

## Data Protection Measures
- AES-256-GCM encryption at rest
- TLS 1.3 encryption in transit
- Field-level encryption for PII
- Automatic data purging after engagement completion

## Sub-processors
- Cloud infrastructure provider (data storage)
- Email service provider (notifications)
- AI model provider (analysis)
