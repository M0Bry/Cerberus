  that automates the full security assessment lifecycle using multi-agent AI.

  Tech Stack:
    Backend:    Python 3.13 · FastAPI 0.139 · SQLAlchemy 2.0 · Celery 5.4
    Frontend:   React 18.3 · TypeScript 5.8 · Vite 6.3 · Tailwind 3.4
    Database:   PostgreSQL 17 · Redis 7 · Alembic migrations
    AI/ML:      DeepSeek · Kimi · Qwen · Z.ai · OpenAI · Anthropic · Ollama
    Infra:      Docker · Kubernetes · Terraform · Nginx 1.27 · Prometheus · Grafana
    Plugins:    14 attack categories · 50+ sub-modules · Dynamic plugin loading
